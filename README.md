## How to choose

- Which agent harnesses and authentication methods does it support?
- Where does the agent execute: your machine, a server you manage, or a hosted environment?
- Can you review diffs, approve actions, and resume work from another device?

## Desktop and project workspaces

- [AionUi](https://github.com/iOfficeAI/AionUi) - Cowork app that brings multiple CLI agents into a shared desktop interface. **Desktop app.**
- [CodeNomad](https://github.com/NeuralNomadsAI/CodeNomad) - Desktop and browser workspace for OpenCode sessions, projects, and Git worktrees. **OpenCode client.**
- [CodexMonitor](https://github.com/Dimillian/CodexMonitor) - Tauri app for managing Codex conversations and agents across local workspaces. **Codex client.**
- [Nimbalyst](https://github.com/nimbalyst/nimbalyst) - Visual workspace for managing coding-agent sessions and reviewing their work. **Desktop app.**
- [opcode](https://github.com/winfunc/opcode) - Desktop GUI for Claude Code sessions, custom agents, and usage tracking. **Claude Code client.**
- [OpenChamber](https://github.com/openchamber/openchamber) - Workspace for running and reviewing OpenCode-powered coding work across desktop and web. **OpenCode client.**
- [OpenWork](https://github.com/different-ai/openwork) - OpenCode-powered desktop cowork app for working with local files and shared capabilities. **Desktop app.**
- [Vibe Kanban](https://github.com/BloopAI/vibe-kanban) - Task board and workspaces for planning coding-agent work and reviewing diffs. **Agent workbench.**

## Mobile and remote access

- [CloudCLI](https://github.com/siteboon/claudecodeui) - Web interface for accessing coding-agent sessions and projects from desktop or mobile browsers. **Web client.**
- [Happy](https://github.com/slopus/happy) - Mobile and web client for interacting with Claude Code and Codex sessions. **Mobile and web client.**

## Terminal and session navigation

- [Agent Sessions](https://github.com/jazzyalex/agent-sessions) - macOS app for searching local coding-agent histories and resuming supported sessions. **Session browser.**
- [Claude Squad](https://github.com/smtg-ai/claude-squad) - Terminal interface for managing several coding-agent sessions in parallel. **Terminal app.**

## Contributing

Missing something useful? Read the [contribution guide](CONTRIBUTING.md) and open an issue or pull request with an official source.

The machine-readable [list.json](list.json) includes a primary-source link and a documentation-check date for every entry. Descriptions are editorial summaries of upstream documentation; inclusion does not imply hands-on testing, a security audit, or endorsement. Hosted services and source code may have different terms.

To update the list, edit `list.json`, run `bun run build`, then `bun run check`. The README is generated; avoid editing it directly.
